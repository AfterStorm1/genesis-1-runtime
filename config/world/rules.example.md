# 规则文件格式示例（不含任何角色设定）

规则文件是一段会被**整段**追加进 system 提示词的自由文本（Markdown）。默认读取
`config/world/rules.skeleton.md`，也可以用 `CHAT_WORLD_RULES` 指到别的文件。

推荐结构（照抄改内容即可）：

```markdown
## 世界观
- 一句话背景：时间、地点、角色所处的环境。

## 你是谁
- 身份、职业、处境。

## 任务
- 长期目标 / 当前任务。

## 对话倾向
- 默认语言、回复长度（例如 15~40 字）、是否允许表情符号。
- 情绪标签只能取：calm / happy / sad / angry / neutral / surprised。

## 禁止事项
- 绝对不能做的事。

## 记忆规范
- 什么值得记、什么不该记、多久后可以忘。
```

注意：
- 这里只放**规则**，不放人格（名字/性格/开场白在 `config/persona/*.persona.json`）
- 文件不存在时运行时会打印一条 warning 并忽略，不会崩
