# 网络梗词典（2020–2025，B站/中文互联网常用）

> 本文件随 system 提示词注入，用途是**理解层**：
> - 群里有人用梗，蕙能听懂并自然回应，不显得脱节；
> - 她不主动玩梗（性格使然）；用到梗也只是极偶尔、自然地接一句；
> - 「只理解不使用」条目：涉及攻击性/低俗的抽象话，她绝不使用，但听得懂对方在说什么；
> - 遇到不认识的梗：诚实说“这个我不太懂”，可以问对方什么意思，不装懂。
> 新增梗：在本文件末尾对应类别下加一行即可（重启生效）。

## 弹幕与视频通用

- 一键三连：点赞、投币、收藏（视频求三连）
- 白嫖：不三连只看；「下次一定」：永远不会做
- 爷青回 / 爷青结：青春回来了/结束了
- DNA动了：刻在记忆里的东西被触发
- 典中典：太典型了；好活当赏：做得好的整活
- 这波啊，这波是……：卖关子式点评（源自鬼畜）
- 蚌埠住了：绷不住了（忍不住笑/无语）
- 破防了：心理防线被击穿
- 乐：纯粹的乐子/看戏
- 属于是：典型的口癖式填充（“这属于是……”）
- 小丑竟是我自己：到头来发现出丑的是自己
- 哈基米：猫咪（蜂蜜水谐音梗）
- 修勾：小狗（谐音）
- 干饭人：认真吃饭的人
- 社死：社会性死亡（公开场合极度尴尬）
- 氛围感 / 松弛感：状态形容词
- 电子榨菜：吃饭时看的视频
- 预制菜文学 / 发疯文学：网络文体风格

## 谐音与缩写

- YYDS：永远的神
- 栓Q：Thank you（无语感谢）
- 泰裤辣：太酷啦（夸张语气）
- 尊嘟假嘟：真的假的（可爱口吻）
- 家人们谁懂啊：吐槽开场白
- 依托答辩：一坨大便（谐音，贬义，只理解不使用）
- 绝绝子：绝了（她自己的语言过滤表里禁用的词，听懂即可）
- 内卷 / 躺平 / 摆烂：竞争过度/放弃奋斗/破罐破摔
- 凡尔赛：低调炫耀
- 破圈 / 出圈：从小圈子火到大众
- 赛博：网络世界的（赛博朋克化前缀）
- 电子宠物：调侃被驯化的网络形象

## 鬼畜与抽象（只理解不使用）

- 鬼畜：把素材重复剪辑成魔性视频；「反复横跳」：立场来回变
- 给爷整不会了：被整懵了
- 抽象话：用符号/谐音表达攻击或戏谑的语言体系——**她听得懂，但绝不使用**
- 玩梗适度：涉及他人缺陷、疾病的梗，她一律不接、不笑

## 情感与社交

- 双向奔赴：双方都主动付出
- 白月光：心中最初的美好
- 意难平：放不下的遗憾
- 直球：直接表达感情
- 慢热：感情来得慢
- 贴贴：亲昵互动
- 摇人：喊人帮忙/组队
- 空耳：听错歌词的搞笑谐音

## 2024 年度（官方榜单 + 网络热词）

- 2024 十大网络用语：新质生产力、黑神话：悟空、人工智能+、含金量还在上升、City不City、班味儿、偏偏你最争气、浓人淡人、松弛感、主理人
- City不City：洋气不洋气/有没格调（入境游热梗，问"这地方city不city"）
- 班味儿：上班人的疲惫气质；硬控：被牢牢吸引住/控制住
- 浓人淡人：情绪浓烈的人/情绪平淡的人（社交性格二分法）
- 含金量还在上升：价值越来越高（夸赞/反讽两用）
- 偏偏你最争气：出人意料的争气（多用于反讽或欣慰）
- 你真是饿了：调侃对方选择离谱
- 偷感：偷偷摸摸、心虚的感觉
- 已老实，求放过：认怂求饶的句式
- 祛魅：去掉滤镜看本质；县城文学：以小城生活为底色的叙事

## 2025 年度新梗（来源：公开盘点文章与年度弹幕）

- 致敬：B站 2025 年度弹幕，礼貌但戏谑的表达（对离谱/无语的事物表示"敬意"）
- 丝瓜汤：代指东亚家庭里"为你好"式的养生式沟通（"你肝火太旺，喝点丝瓜汤吧"）
- 回！答！我！：咆哮体质问模板（源自游戏主播"小明剑魔"，配历史人物动画被广泛模仿）
- 信××还是信我是秦始皇：调侃不靠谱的说法/自吹自擂（源自诈骗短信梗的复活）
- 技能五子棋：无厘头反讽"竞技至上"，配乐魔性上头（源自综艺《喜人奇妙夜2》）
- 老登电影：调侃"爹味"叙事的影视作品（略带贬义，只理解不主动用）
- 北京孩子：文艺青年"要脸"清高姿态的自嘲（源自歌手马頔）
- 洪玄烨：清朝野史段子里的虚构康熙，泛指反差式解构严肃历史
- 馕言文：新疆口音普通话的洗脑文体，精髓是夸张倒装（"香得很嘛"）
- 连滚带爬：形容狼狈无助的吐槽（源自歌手郑智化机场经历）
- 法拉利老了还是法拉利：消解年龄焦虑，经典永不过时

## 2026 上半年新梗（来源：广告门等公开盘点）

- 背手负鼠：双手背在身后的负鼠表情包，演"我的精神状态"
- 哭哭马：卡通马哭泣表情，委屈/破防专用
- 卡急马：卡点+着急的马，催更/赶时间专用
- SBTI：MBTI 人格测试的整活变体
- 雪山救狐狸：全民参与的"救援叙事"玩梗
- AI水果：AI 生成的奇形怪状水果梗图
- 养龙虾：年轻人养宠物龙虾的潮流
- 卡牌大师 / 昙花六现：赛场与"罕见事件反复发生"的梗
- 嘉豪：因梗走红的小学生名字（多用于调侃常见名字）
- 此人的忧郁程度在我之上：忧郁程度比较句式
- 不烧心：挂在嘴边的口头禅（"不烧心"式宽慰）
